Fish shell CLI · Bot API & MTProto · MCP server

Terminal to Telegram, in one pipe.

paste-gram (ptg) sends text, piped command output, files, and whole directories to a Telegram chat through the Bot API, or as your own account through MTProto. Files over 50 MB are compressed and split automatically. Works on Linux and macOS, over SSH, in cron and CI, and from AI coding agents.

Quick start

Create a bot with @BotFather, grab your chat ID, and you are three commands away from sending your first log.

  • Install
  • Configure
  • Send

Step 1

Install

With fisher, the Fish plugin manager.

fisher install behnambagheri/fish-paste-gram

Step 2

Configure

Universal variables persist across sessions.

set -Ux TELEGRAM_TOKEN 'your_bot_token'
set -Ux TELEGRAM_CHAT_ID '123456789'

Step 3

Send

Text, stdin, files, or folders.

df -h | ptg
ptg ~/logs/app.log
ptg ~/Documents/project

What you can do with it

Anything you can print or save in a shell, you can drop into a Telegram chat, from a laptop or a server three hops away.

01

Server logs to Telegram

Grab log files or journalctl output from a remote machine over SSH without scp.

02

Pipe any output

kubectl get pods | ptg, docker logs app | ptg, df -h | ptg. Long output is chunked.

03

Shell notifications

Alert yourself when a build, deploy, backup, or cron job is done.

04

Large files and folders

Directories become .tgz archives; anything over the 50 MB bot limit is split into 49 MB parts.

05

Personal account mode

Send as yourself with MTProto, to Saved Messages by default, with guardrails against spam.

06

AI agent delivery

An MCP server and Agent Skill let Claude Code, Codex, Cursor, and other agents send you reports on Telegram.

Built for AI agents

Ask Claude Code, Codex, Cursor, or Claude Desktop to “send me the report on Telegram” and the file lands in your chat. paste-gram ships three pieces for agents.

MCP

MCP server

Tools for any MCP client: send_message, send_files, list_targets, and check_setup.

Skill

Agent Skill

Teaches skill-aware agents when and how to call paste-gram, and what not to send.

CLI

Predictable CLI

No prompts in non-interactive shells, clear errors, and non-zero exit codes on failure.

Install the plugin (Skill and MCP server together). Set TELEGRAM_TOKEN and TELEGRAM_CHAT_ID first.

/plugin marketplace add behnambagheri/fish-paste-gram
/plugin install paste-gram@paste-gram

Register the server. It needs the mcp Python package.

python3 -m pip install mcp
codex mcp add paste-gram -- python3 /path/to/fish-paste-gram/mcp-server/paste_gram_mcp.py

Any agent with shell access can call the CLI directly, from bash, zsh, or any tool runner.

fish -c 'paste-gram $argv' -- ./report.pdf

Then just ask

  • Run the tests and send me the failure report on Telegram.
  • When the build finishes, message me on Telegram with the result.
  • Compress the logs/ folder and send it to me on Telegram.
On by default

Agent guardrails

File sends are limited to allowed folders, credential-like files such as .env, .ssh, and *.pem are refused, and destinations are limited to your own chat and configured aliases. See the README for every option.

Features

Small enough to read in one sitting, complete enough for daily ops work.

  • Text, stdin, files, directories, and multiple inputs bundled into one named archive
  • Captions with -m, editor support for long captions, and Telegram HTML with --html
  • Send to several chats at once with --id and a JSON alias map
  • Optional hostname, command line, and path in captions
  • Custom Bot API URL, HTTP/SOCKS proxy, and MTProxy support
  • Fish completions and verbose diagnostics with redacted secrets
  • MCP server and Agent Skill for Claude Code, Codex, Cursor, and other AI agents
  • Default transport per machine with PASTEGRAM_DEFAULT_MODE=bot|mtproto

FAQ

Short answers to the questions people ask most.

How do I send a file to Telegram from the command line?

Install paste-gram, set TELEGRAM_TOKEN and TELEGRAM_CHAT_ID, then run ptg /path/to/file. Directories work the same way.

How do I pipe command output to Telegram?

Pipe it into ptg, for example some_command 2>&1 | ptg. Long output is split across several messages.

Can a Telegram bot send files larger than 50 MB?

The Bot API caps uploads at 50 MB, so paste-gram compresses and splits large inputs into 49 MB parts. Rejoin them with cat archive.tgz_* > archive.tgz. MTProto mode sends the file whole.

Does it work in bash or zsh?

Yes, as long as Fish is installed: fish -c 'paste-gram $argv' -- ./report.pdf.

Can AI agents like Claude Code or Codex use it?

Yes. It ships an MCP server and an Agent Skill. See Built for AI agents.
